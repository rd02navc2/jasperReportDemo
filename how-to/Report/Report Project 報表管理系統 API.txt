## AppReport 應用程式報表系統

1. 取得應用程式專櫃統計資料 API
   - API: POST /AppReport/getAppCounter[cite: 1]
   - 說明: 接收前端請求參數與分頁資訊（page、rows、sidx、sord），呼叫 ReportService 查詢應用程式專櫃統計清單與總筆數，並回傳分頁格式的 JSON 資料[cite: 1]
   
## Asset 資產盤點系統

1. 取得盤點日期清單 API
   - API: GET /Asset/getInventoryDate
   - 說明: 查詢所有資產盤點日期的表頭資訊、產生類型與結案日期狀態

2. 取得資產盤點明細 API
   - API: POST /Asset/getAssetInventory
   - 說明: 根據指定的盤點日期與排序條件，查詢資產盤點的詳細清單與員工擁有者資訊

3. 取得資產類別選單 API
   - API: GET /Asset/getAssetType
   - 說明: 取得系統中所有的資產類別並組成 HTML <select> 下拉選單供前端使用

4. 上傳資產 Excel 檔案 API
   - API: POST /Asset/uploadExcel
   - 說明: 驗證使用者登入狀態，上傳並解析資產 Excel 盤點檔案，並對照員工與資產編號回傳明細

5. 儲存匯入資產資料 API
   - API: POST /Asset/saveImport
   - 說明: 接收並儲存從前端傳入的匯入資產盤點資料

6. 儲存資產資料 API
   - API: POST /Asset/saveAsset
   - 說明: 針對指定的盤點日期與資料集進行資產盤點資料的儲存與更新

7. 刪除全部資產盤點資料 API
   - API: POST /Asset/deleteAll
   - 說明: 刪除指定盤點日期的所有資產盤點資料

8. 刪除單筆資產資料 API
   - API: POST /Asset/delete
   - 說明: 刪除指定盤點日期與自身財產編號的單筆資產資料

9. 資產報廢 API
   - API: POST /Asset/scrapped
   - 說明: 將指定盤點日期與財產編號的資產標記為報廢狀態

10. 建立新資產盤點 API
    - API: POST /Asset/newAsset
    - 說明: 檢查驗證狀態後發起新的個人設備資產盤點任務，並寄送盤點通知郵件給全體同仁

11. 取得員工個人資產 API
    - API: POST /Asset/getStaffAsset
    - 說明: 取得目前登入員工名下的個人設備資產清單與盤點確認狀態

12. 取得已報廢資產 API
    - API: POST /Asset/getAssetScrapped
    - 說明: 依據指定的銷售/報廢日期區間與財產編號查詢已報廢的資產清單

13. 提交個人資產盤點確認 API
    - API: POST /Asset/submit
    - 說明: 供登入員工提交並確認其名下的個人資產盤點結果

14. 發送未盤點人員提醒通知 API
    - API: POST /Asset/inform
    - 說明: 檢查尚未完成盤點確認的人員，並批次發送資產盤點再次提醒通知電子郵件
	
## Budget 預算管理系統

1. 取得預算參數設定 API
   - API: GET /Budget/getBGParam[cite: 2]
   - 說明: 取得預算申請與審核相關的電子郵件收件人與副本參數設定[cite: 2]

2. 儲存預算參數設定 API
   - API: POST /Budget/saveBGParam[cite: 2]
   - 說明: 接收並儲存預算申請與審核的電子郵件收件人與副本設定[cite: 2]

3. 取得預算表頭清單 API
   - API: GET /Budget/getBudgetHeader[cite: 2]
   - 說明: 查詢所有月份的預算表頭資訊、審核狀態、操作人員與時間、以及退回原因[cite: 2]

4. 取得預算明細資料 API
   - API: POST /Budget/getBudgetDetail[cite: 2]
   - 說明: 根據指定的預算月份與排序條件查詢各樓層、部門與櫃位的每日預算明細資料[cite: 2]

5. 上傳預算 Excel 檔案 API
   - API: POST /Budget/uploadExcel[cite: 2]
   - 說明: 驗證使用者登入狀態，上傳並解析預算 Excel 檔案，並回傳對應的每日預算明細清單[cite: 2]

6. 儲存預算資料 API
   - API: POST /Budget/save[cite: 2]
   - 說明: 儲存指定月份的預算資料、檢查是否尚有櫃位預算為 0，若完整則發送預算審核通知信並更新狀態為審核中[cite: 2]

7. 更新預算樓層資訊 API
   - API: POST /Budget/updateFloor[cite: 2]
   - 說明: 根據目前的櫃位清單更新指定月份預算資料中的樓層對應資訊[cite: 2]

8. 提交或審核預算 API
   - API: POST /Budget/submit[cite: 2]
   - 說明: 針對指定月份的預算進行核准或退回動作，並寄送對應的通知信給申請人[cite: 2]

9. 刪除單筆預算資料 API
   - API: POST /Budget/delete[cite: 2]
   - 說明: 刪除指定月份、部門與櫃位的單筆預算資料[cite: 2]

10. 刪除全部預算為零的資料 API
    - API: POST /Budget/delete0[cite: 2]
    - 說明: 刪除指定月份中預算資料為全部為零的相關紀錄[cite: 2]

11. 取得例外專櫃清單 API
    - API: POST /Budget/getExceptCounter[cite: 2]
    - 說明: 查詢預算計算或處理中的例外專櫃清單[cite: 2]

12. 新增例外專櫃 API
    - API: POST /Budget/addExceptCounter[cite: 2]
    - 說明: 根據傳入的專櫃代號新增一筆例外專櫃資料[cite: 2]

13. 刪除例外專櫃 API
    - API: POST /Budget/delExceptCounter[cite: 2]
    - 說明: 根據傳入的專櫃代號刪除對應的例外專櫃資料[cite: 2]

14. 檢查預算完成狀態 API
    - API: POST /Budget/isCompletion[cite: 2]
    - 說明: 檢查指定月份的預算資料是否完整，若完整則自動送出審核[cite: 2]

15. 重新計算預算 API
    - API: POST /Budget/reCalc[cite: 2]
    - 說明: 針對指定月份的預算執行重新計算與核准狀態更新處理[cite: 2]

7. 取得活動統計資料 API

1. 產生出勤異常 Excel 報表 API

    POST /Report/genOffPunchExcel

    功能說明：根據查詢條件比對排班與刷卡紀錄，產出出勤異常 Excel 報表並回傳下載路徑與寫入下載 Log。

2. 產生上下班刷卡不成對 Excel 報表 API

    POST /Report/genUnpairExcel

    功能說明：比對排班與刷卡紀錄以篩選出未成對的刷卡資料，匯出成 Excel 檔並回傳下載路徑與紀錄 Log。

3. 產生加班異常 Excel 報表 API

    POST /Report/genOvertimeExcel

    功能說明：解析並比對加班異常資料，生成相對應的 Excel 報表檔並回傳下載路徑與紀錄 Log。

4. 產生預算日明細 Excel 報表 API

    POST /Report/genBudgetExcel

    功能說明：將前端傳入的指定月份預算勾選資料，匯出為預算日明細 Excel 報表並回傳下載路徑。

5. 產生資產盤點 Excel 報表 API

    POST /Report/genAssetExcel

    功能說明：接收指定的資產盤點資料與日期，產生資產盤點 Excel 報表並回傳下載路徑。

6. 產生個人資產設備 Excel 報表 API

    POST /Report/genStaffAssetExcel

    功能說明：將傳入的員工個人資產資料，產出為個人資產設備 Excel 報表並回傳下載路徑。

7. 報表檔案下載 API

    POST /Report/download

    功能說明：依據傳入的檔案路徑讀取伺服器端實體檔案，並透過 HTTP Response 串流提供前端下載。

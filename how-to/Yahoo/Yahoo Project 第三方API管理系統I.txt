Yahoo Project 第三方API管理系統

## BossReport 高階主管報表 API

1. 取得高階會員紀錄 API[cite: 7]
   GET /BossReport/getBossMember[cite: 7]
   接收分頁與查詢條件，取得高階會員相關的掃描日期、會員編號、相關資訊、性別與年齡等紀錄清單，並回傳分頁資訊與執行狀態[cite: 7]。
   
## Chicken 銷售資料管理 API

1. 取得銷售資料 API[cite: 8]
   GET /Chicken/getSaleData[cite: 8]
   接收分頁與查詢條件，取得銷售資料清單，包含銷售日期、星期、客戶數、餐飲收入、建立日期與更新日期，並回傳分頁資訊與執行狀態[cite: 8]。

2. 儲存銷售資料 API[cite: 8]
   GET /Chicken/saveSaleData[cite: 8]
   接收傳入的銷售日期、客戶數與餐飲收入參數，執行銷售資料的儲存或更新作業，並回傳執行狀態[cite: 8]。
   
## Finance 財務管理 API

1. 取得訂單資料 API[cite: 8]
   GET /Finance/getOrder[cite: 8]
   取得使用者的公司代號，依照不同平台（Yahoo、Rakuten、PChome）計算不同的起訖日期區間，查詢並回傳訂單明細與成本價格資料[cite: 8]。

2. 取得運費資料 API[cite: 8]
   GET /Finance/getShippingFee[cite: 8]
   依據平台類型與公司代號計算日期區間，查詢並回傳相關運費與訂單明細資料[cite: 8]。

3. 取得退貨資料 API[cite: 8]
   GET /Finance/getReturn[cite: 8]
   依據平台條件取得指定區間內的退貨訂單資料，並回傳退貨建立日、退貨代號、退貨扣款日及成本價等欄位[cite: 8]。

4. 取得退貨運費資料 API[cite: 8]
   GET /Finance/getReturnFee[cite: 8]
   針對 Yahoo 與 PChome 平台計算退貨相關的運費與明細資料，並依條件回傳對應的退貨運費金額[cite: 8]。

## MallCategory 商城類別管理 API

1. 取得 Yahoo 商城類別 API[cite: 10]

3. 取得 PChome 商城類別 API[cite: 10]
   * GET /MallCategory/getPCMallCategory[cite: 10]
   * 依據傳入的層級與類別編號參數，向 PChome 商店街端點發送請求，取得並回傳指定供應商的商城分類節點資訊[cite: 10]。

4. 取得 Momo 商城類別 API[cite: 10]
   * GET /MallCategory/getMomoMallCategory[cite: 10]
   * 透過系統屬性進行登入驗證與 AES 解密，向 Momo 商城端點查詢各層級的類別資料，並回傳分類清單與執行狀態[cite: 10]。

4. 取得訂單詳細資料 API[cite: 10]

## POSUpgrade POS 系統版更管理 API

1. 儲存 POS 版更申請 API[cite: 11]
   * POST /POSUpgrade/savePOSUpgrade[cite: 11]
   * 接收前端傳入的版更申請資料，執行儲存、複製相關上傳檔案（暫存區至正式區），並自動排程發送版更申請通知信件給相關人員[cite: 11]。

2. 上傳 POS 版更相關檔案 API[cite: 11]
   * POST /POSUpgrade/uploadImage[cite: 11]
   * 檢查使用者登入狀態，解析多部分表單內容（Multipart），將上傳的檔案儲存至系統設定的暫存目錄（POSUpgradeTemp），並回傳檔案目錄與檔名[cite: 11]。

3. 取得 POS 版更清單 API[cite: 11]
   * GET /POSUpgrade/getPOSUpgrade[cite: 11]
   * 根據分頁、排序及查詢條件取得 POS 版更申請清單，包含公司代號、狀態、狀態名稱、版本編號、申請日期、申請人資訊、說明、是否為 POS 相關與附件狀態等資訊[cite: 11]。

4. 依編號取得 POS 版更詳細資料 API[cite: 11]
   * GET /POSUpgrade/getPOSUpgradeByNo[cite: 11]
   * 依據傳入的公司代號與版本編號查詢單筆版更的詳細記錄，包含確認人員、退回資訊、完成日期、備忘錄及檔案路徑等完整內容[cite: 11]。

5. 執行 POS 版更審核/核准 API[cite: 11]
   * POST /POSUpgrade/doApprove[cite: 11]
   * 處理版更的接收、確認完成或上版作業，並根據狀態自動寄送通知信件或透過 Line 傳送更版完成訊息[cite: 11]。

6. 儲存 IT 版更備忘錄 API[cite: 11]
   * POST /POSUpgrade/saveITMemo[cite: 11]
   * 依據公司代號與版本編號更新並儲存 IT 相關的備忘錄（it_memo）內容[cite: 11]。

7. 執行 POS 版更退回 API[cite: 11]
   * POST /POSUpgrade/doReturn[cite: 11]
   * 處理版更申請的退回作業，更新狀態並寄送退回原因通知信件給申請人[cite: 11]。
   
## Product 產品管理系統

1. 產品批次動作 API
POST /Product/submit
處理批次動作如ApproveOn、Off、ReOn及Delete，依據指定平台更新產品狀態

2. 查詢產品列表 API
GET /Product/getProduct
取得分頁產品清單，支援DataTables與jqGrid參數，回傳市場價、售價、成本、庫存及佣金率

3. 新增產品 API
POST /Product/saveProduct
驗證產品名稱長度、描述、公司是否存在及平台格式，儲存新產品並發送通知郵件

4. 更新產品 API
POST /Product/saveUpdProduct
修改現有產品細節，若更新核心財務欄位或名稱會處理平台狀態變更並儲存歷史快照

5. 上傳產品圖片 API
POST /Product/uploadImage
處理多部分檔案上傳，限制檔案大小在1MB以內並儲存至指定供應商目錄

6. 依ID查詢產品 API
GET /Product/getProductById
根據主產品ID與公司代碼取得詳細規格、類別對應及多平台狀態

## Supplier 供應商管理系統

   * **URL**: `POST /Supplier/getSupplier`[cite: 14]
   * **功能說明**: 讀取請求中的JSON與分頁參數，透過供應商服務取得符合條件的供應商清單，並將公司代碼、名稱、地址與電子郵件包裝成JSON陣列回傳[cite: 14]。

   * **URL**: `POST /Supplier/getSupplierByID`[cite: 14]

3. 儲存供應商資料 API[cite: 14]

4. 刪除供應商資料 API[cite: 14]
   * **URL**: `POST /Supplier/deleteSupplier`[cite: 14]
   * **功能說明**: 根據傳入的參數執行供應商刪除作業，成功時回傳成功標記，失敗時則攔截例外並回傳錯誤訊息[cite: 14]。

## WebSign 網頁簽到管理系統

1. 取得簽到資料 API[cite: 14]
   * **URL**: `POST /WebSign/getSignData`[cite: 14]
   * **功能說明**: 從 Session 取得目前登入使用者的公司編號，讀取請求中的JSON查詢條件（包含搜尋公司代碼與銷售起始日期），透過網頁簽到服務取得簽到清單，將公司代碼、名稱、簽到時間、簽到退時間、總時數、總分鐘數、存取代碼與名稱及服務結束時間格式化後包裝為JSON陣列回傳；成功時寫入Info日誌，失敗時記錄錯誤[cite: 14]。

IpTrackingFilter 失敗偵測機制

過濾器在下游服務回應後，攔截狀態碼 401 Unauthorized 或 403 Forbidden， 自動非同步寫入 gateway_login_failure_log。 帳號來自 Query Param ?username=， 缺少時記為「未知用戶」。網關節點 IP 在服務啟動時由 InetAddress.getLocalHost() 解析並快取。

連線範例 new-surrounding member-service-route payment-gateway-v2 admin-api-route 唯一識別鍵值，建議使用小寫英文加 - 連字號，不可含空格或特殊符號
連線範例 lb://member-service lb://payment-service http://localhost:8081 http://192.168.1.100:9090 lb:// 前綴表示透過 Spring Cloud LoadBalancer 服務發現；http:// 直接指向固定 IP 端點
連線範例 /api/v1/member/** /api/v2/payment/** /admin/internal/** /public/static/** ** 萬用符號可匹配多層子路徑，對應至 Spring Cloud Gateway Path Predicate
連線範例 0 1 -1 100 數字越小優先級越高；當多條路由路徑重疊時，Order 決定匹配順序（預設 0）
連線範例 active → enabled: true inactive → enabled: false 僅 active 狀態的路由會被網關載入並生效；切換為 inactive 後路由將從轉發層卸載
連線範例 
[{"name":"Path","args":{"pattern":"/api/**"}},{"name":"Method","args":{"methods":"GET,POST"}}]
留空時系統將自動使用上方「Path 路徑」欄位產生預設 Predicate；填入後將完整覆蓋預設設定
連線範例 StripPrefix=1 AddRequestHeader=X-Flow,Gateway RewritePath=/api/(?<segment>.*),/$\{segment} 多個 Filter 以英文逗號分隔；每筆格式為 FilterName=arg1,arg2，對應 Spring Cloud Gateway 內建 GatewayFilter

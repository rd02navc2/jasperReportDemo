## SyncBISales BI日營業部門業績分析系統

1. BI日營業部門業績分析 API
   - API: GET /syncBISales[cite: 12]
   - 說明: 執行 BI 日營業部門業績分析作業，透過 SyncBISalesEntry 接收 `sFromDate` 與 `sEndDate` 參數，並呼叫 `doSync(0, sFromDate, sEndDate)` 進行日營業部門業績資料的刪除與重新儲存分析[cite: 12]

2. BI備份日營業部門業績分析 API
   - API: GET /syncBISalesBackup[cite: 12]
   - 說明: 執行 BI 備份日營業部門業績分析作業，透過 SyncBISalesBackupEntry 接收 `sFromDate` 與 `sEndDate` 參數，並呼叫 `doSync(1, sFromDate, sEndDate)` 進行備份資料庫的日營業部門業績分析作業[cite: 12]

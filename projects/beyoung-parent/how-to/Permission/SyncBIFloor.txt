## SyncBIFloor BI日樓層業績分析系統

1. BI日樓層業績分析 API
   - API: GET /syncBIFloor[cite: 11]
   - 說明: 執行 BI 日樓層業績分析作業，透過 SyncBIFloorEntry 接收 `sFromDate` 與 `sEndDate` 參數，並呼叫 `doSync(0, sFromDate, sEndDate)` 進行日樓層業績資料的刪除與重新儲存分析[cite: 11]

2. BI備份日樓層業績分析 API
   - API: GET /syncBIFloorBackup[cite: 11]
   - 說明: 執行 BI 備份日樓層業績分析作業，透過 SyncBIFloorBackupEntry 接收 `sFromDate` 與 `sEndDate` 參數，並呼叫 `doSync(1, sFromDate, sEndDate)` 進行備份資料庫的日樓層業績分析作業[cite: 11]
